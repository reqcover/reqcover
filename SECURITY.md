# ReqCover Security Policy
Being a test tool, ReqCover is meant to be a pure development tool.
It runs inside your test JVM during the build, and its code is not intended to be shipped as part of an actual production system.

Therefore, at present, we believe that coordinated disclosure of security vulnerabilities is not required.
If you find a security vulnerability, please treat it as a bug and disclose it via the [Issue Tracker](https://github.com/reqcover/reqcover/issues).
If you believe that in your situation this is wrong and the disclosure should happen in private, please contact one of the [authors](AUTHORS).

Only the latest release receives fixes.
